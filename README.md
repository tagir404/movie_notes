# Movie Match

Приложение для подбора фильма на вечер.

> **Рекомендуется запускать приложение в Profile mode** для корректной оценки производительности.

> **Важно:** для работы приложения необходимо включить VPN, так как TMDB API недоступно из России.

## Запуск

Установить зависимости:

```bash
flutter pub get
```

### Profile

```bash
flutter run --profile
```

Или через VS Code:

1. Выбрать подключённое устройство.
2. Открыть `Run and Debug`.
3. Выбрать **Flutter (Profile Mode)**.
4. Запустить приложение.

### Debug

```bash
flutter run
```
